# Options Pricing — Black-Scholes on TSMC (TSM)

Pricing and implied volatility analysis on TSMC options using the Black-Scholes model.

**Topics covered:**
- BSM formula implementation (calls & puts) + call-put parity verification
- Implied volatility extraction via Newton-Raphson and scipy solvers
- Live market data via Yahoo Finance (yfinance)
- Liquidity filtering and volatility smile / term structure visualization
- Comparison of computed IV vs market IV

**Stack:** Python · numpy · pandas · scipy · matplotlib · yfinance# project-pricing-option-tsmc
